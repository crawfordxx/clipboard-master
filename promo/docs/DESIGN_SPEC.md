# Clipboard Master · 小马管家宣传片

## 制作模式与产品简报

2026-09-13 用户明确授权“方案你来定吧，继续”：采用自主自由创作，不套 Ink Press 的视觉。随后用户明确要求小马必须体现 Clipboard Master；最终角色改成抱着大号剪贴板的小马管家。六张原始小马候选全部保留，新增统一角色是针对用户明确修订请求生成，并非自动重抽。

产品：原生 macOS 菜单栏 / Windows 托盘剪贴板历史工具。主受众：每天反复复制文字、链接、截图的创作者和办公用户。用途：README 首屏的可点播宣传片，横版1920×1080、30fps、约37秒、中文。

必须展示：新的小马+剪贴板识别；文字与图片历史；搜索并重新复制（不声称自动粘贴）；图片缩略图与本地历史窗口；非打断更新状态；本机存储；仓库入口。

## 三个视觉方向与选择

1. 蓝白小马管家：暖而不幼稚的原生桌面小助手，真实UI作证据。**选中**。
2. 深蓝科技舞台：更冷峻、更强调3D，容易压过可爱IP。弃用。
3. 纸墨故事书：纸墨/衬线适合叙事，但与原生界面及蓝白品牌不一致。弃用。

## 产品视觉 Tokens

来源：MenuPanelView.swift 与新角色图。UI原字体系为SF系统无衬线、中文PingFang；字号10/11/12/15，强调semibold，圆角9/10/12/14/16，间距8/10/12/16。视频放大为系统无衬线中文，禁另加无关衬线字体。

- 背景：#EDF5FC / #F7FAFE；表面：#FFFFFF；品牌蓝：#2463D4；墨色：#102A50；次级字：#526780；角色奶白：#FFF8ED；少量深场：#122744。
- 标题84–100px/700，功能字幕64px/600，辅助38px/500，URL36px/600；中文行高1.25，英文字距-0.025em。
- 画面安全边距100px；组件圆角28–48（图标80）；源截图保持原比例。投影淡蓝，不用霓虹、金粉、赛博网格。
- 动效性格：亲和友好，主入场26f，有限过冲1.04，无手持抖动；卡片落地保留源卡真实过冲参数。品牌落定至少30f，UI阅读至少30f。镜头不逐拍震动。

## 视觉放行与素材冻结

已自主放行。制作前生成三张1920×1080 HTML静态styleframe并截图检查。主角只一只，视频不展示六个候选、无无关角色。公开官网文本不作真实用户记录；四条冻结示例已写入native capture脚本。

音频不使用不明出处样本，素材来源与处理见audio-plan.md。BGM/noBGM两版共享同一画面/SFX时间线。所有帧逻辑确定性，禁Date.now/Math.random。

## 终检后记录的具体适配

- row-embed为4条真实原生行，使用该卡12+i×9的等间隔，既保留配方也保证可读；outro为4个功能代表裁片，使用源卡3f错峰。通用R2大量卡硬加速不强加到这两张本身定义等间隔的卡上。
- 搜索中文输入最后一字后保留33f，再过滤；比源卡11f更慢，不削减阅读时间。
- S4采用实际完整历史窗口加图片行特写，不提供不存在的独立大图预览界面。更新失败重试是文字说明的真实功能，视频主要演示checking/current。
- S5独立3D卡片放在页面平面的z=20px前方，避免顶部在进入姿态时穿入背景。入场角度只有5°，不为炫技牺牲可读性。
- 带配乐及仅音效版均分别由同一时间线/bgminputProp渲染；为消除两次GPU渲染/编码的微小像素差，最终仅音效版使用共同的视频编码流、保留自己独立渲染的SFX音轨做无损封装。不是从混合配乐轨中移除音乐。封装后再次验证画面哈希及音画对齐。
